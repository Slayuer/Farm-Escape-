# Farm Escape 🥕

A mobile 3D endless runner: a vegetable escapes a chaotic farm.

- **Full design doc:** [`docs/game_design_brief.md`](docs/game_design_brief.md)
- **Engine:** Godot 4 (GDScript)
- **Status:** MVP in progress — see design brief section 24 for MVP scope.

## Getting Started (Godot)

1. Install [Godot 4.x (Standard)](https://godotengine.org/download).
2. Open Godot → **Import** → select this folder's `project.godot` (once created).
3. Press **Play** to run the game.
